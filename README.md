# 밈천지 — 운영진용 사용 가이드

이 문서는 축제 주점 "밈천지"에서 함께 일할 운영진(총괄/주문서버/주방)을 위한 설명서입니다. 개발 관련 상세 내용은 [PROJECT.md](PROJECT.md)를 참고하세요.

> ⚠️ 아직 개발 중인 시스템입니다. 실제 접속 주소와 로그인 계정은 행사 전에 별도로 공지됩니다. 이 문서는 "행사 당일 어떻게 쓰게 될지" 미리 감을 잡기 위한 가이드입니다.

---

## 1. 이 시스템이 뭘 해결해주나요?

지금까지는 손님이 카운터에 와서 말로 주문하고, 종이나 화이트보드에 적어서 주방에 전달하는 방식이었다면, 이 시스템은 그 과정을 폰으로 대체합니다.

- **손님**: 자기 폰으로 QR코드를 찍어서 메뉴를 보고 직접 주문
- **운영진**: 각자 폰(또는 노트북)으로 들어오는 주문을 실시간으로 확인하고 처리

결제는 이 시스템이 대신 해주지 않습니다. **입금 확인은 여전히 운영진이 직접 눈으로 보고 체크**하는 방식이에요 (현금/계좌이체 확인 후 화면에서 "입금확인" 버튼만 눌러주면 됩니다).

---

## 2. 당일 준비물 — 역할별로 여는 화면이 다릅니다

행사 시작 전에 각자 담당한 기기에서 정해진 주소를 미리 열어두세요.

| 역할 | 여는 주소(당일 공지 예정) | 기기 | 로그인 |
|---|---|---|---|
| **총괄** | `/admin/overview` | 노트북 (좌석 전체 + 주문 현황을 한눈에) | 필요 |
| **주문받는 서버** | `/admin/orders` | 폰 | 필요 |
| **주방** | `/admin/kitchen` | 폰 | 필요 |
| (참고) 손님 | `/order/{테이블번호}` | 손님 폰, 테이블 QR코드로 접속 | 불필요 |

- 관리자 화면은 로그인이 필요합니다. 계정은 스태프별로 미리 발급해서 나눠드릴 예정이니, 아이디/비밀번호를 잊어버리지 않게 저장해두세요.
- 로그인은 한 번 하면 그 기기·브라우저에서는 계속 유지되니, 행사 중간에 매번 다시 로그인할 필요는 없습니다.
- **행사 시작 전 리허설 때 반드시 각자 기기에서 접속 테스트를 해보세요.** 와이파이가 잡히는지, 화면이 잘 뜨는지 미리 확인하는 게 제일 중요합니다.

---

## 3. 손님은 이렇게 주문해요 (참고용)

1. 테이블에 붙어있는 QR코드 스캔 → 테이블 번호 확인 화면
2. 메뉴 화면에서 안주/음료 등 카테고리별로 보고 담기
3. 장바구니에서 수량 조절 후 "주문하기"
4. 주문 현황 화면에서 자기가 시킨 메뉴가 대기중/조리중/완료 중 어디쯤인지 실시간으로 확인 가능
5. 추가 주문도 같은 화면에서 계속 가능 (재입장할 필요 없음)

손님이 "제가 시킨 게 어떻게 되고 있나요?"라고 물어보면, 이 주문 현황 화면을 직접 보라고 안내해주시면 됩니다.

---

## 4. 운영진 화면 사용법

모든 관리자 화면은 **좌석 현황(SeatGrid)** 과 **주문 큐(OrderQueue)** 두 가지 요소로 이루어져 있고, 화면마다 보이는 범위와 누를 수 있는 버튼만 다릅니다.

### 🧑‍💼 총괄 (`/admin/overview`)
- 좌석 전체 현황(빈자리/사용중, 얼마나 오래 앉아있는지)과 전체 주문 큐를 한 화면에서 봅니다.
- 할 수 있는 것: **입금확인, 조리완료 체크, 퇴석 처리** — 사실상 세 화면의 기능을 다 가지고 있는 관제탑 역할입니다.
- 퇴석 처리(테이블 정리)는 **총괄만** 할 수 있습니다.

### 🧾 주문받는 서버 (`/admin/orders`)
- 들어오는 주문을 전체적으로 확인합니다.
- 할 수 있는 것: **입금확인**만. 손님이 계좌이체 했다고 하면(또는 현금을 받으면) 여기서 확인 버튼을 눌러주세요.
- 입금확인을 눌러야 그 주문이 주방 화면에 뜹니다. 안 누르면 주방에서는 그 주문이 안 보여요.

### 🍳 주방 (`/admin/kitchen`)
- 입금 확인이 끝난(조리해야 하는) 주문만 보입니다. 아직 입금 안 된 주문은 아예 안 보여요.
- 할 수 있는 것: **조리완료 체크**만. 음식이 나가면 해당 항목을 체크해주세요.

### 상태 아이콘 의미
| 아이콘 | 상태 | 설명 |
|---|---|---|
| 🟠 | 입금대기 | 주문은 들어왔지만 아직 입금 확인 전. 주방엔 안 보임 |
| 🔥 | 조리중 | 입금 확인 완료, 조리 대상 |
| ✅ | 완료 | 서빙 완료. 잠깐 표시됐다가 화면에서 사라짐 |

🟠 입금대기 항목은 항상 화면 맨 위에 고정되어 있어서, 놓치지 않고 먼저 처리할 수 있게 되어 있습니다.

## 5. 당일 주의사항

- **와이파이 연결은 필수입니다.** 접속이 끊기면 실시간 업데이트가 안 됩니다.
- **서버를 함부로 재시작하거나 새로고침을 반복하지 마세요.** 상태가 꼬이거나 순간적으로 데이터가 안 보일 수 있습니다. 화면이 이상하면 먼저 담당 개발자에게 알려주세요.
- 여러 명이 동시에 같은 주문을 처리하려고 하면(예: 같은 항목을 두 명이 동시에 조리완료 누르는 경우) 화면이 자동으로 갱신되니 당황하지 말고 한 번만 눌러주세요.
- 문제가 생기면(화면이 안 뜬다, 주문이 이상하게 보인다 등) 바로 담당 개발자에게 연락 주세요. *(연락처는 행사 전 공지 예정)*

궁금한 점이나 이해 안 되는 부분 있으면 언제든 편하게 물어봐 주세요.
